Here's what the main files do:
- main.ts: starts the Angular application.
- app.ts: contains the root component's TypeScript logic.
- app.html: defines the root component's HTML.
- app.css: styles that component.
- index.html: the main HTML page that hosts the Angular application.
- package.json: records dependencies and project scripts.
- angular.json: configures Angular CLI build and development settings.
